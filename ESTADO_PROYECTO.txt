  * RutinaEjercicio.cs       : Mapea dbo.rutina_ejercicios con JOIN a ejercicios (incluye Titulo, Descripcion, ImagenRuta, Duracion).
  * HistorialPausa.cs        : Mapea dbo.historial_pausas con campos auxiliares para reportes (EstadoFormateado, DuracionTexto).

  * UsuarioDAL.cs            : Autenticar(), ObtenerTodos(), ExisteUsuario(), Insertar(), Actualizar(), RestablecerPassword(), CambiarEstado().
  * EjercicioDAL.cs          : ObtenerTodos(), ObtenerActivos(), Insertar(), Actualizar(), Eliminar(), CambiarEstado().
  * PausaDAL.cs              : ObtenerTodas(), ObtenerActiva(), Insertar(), Actualizar(), Activar(), Eliminar(), ObtenerRutina(), GuardarRutina() [Transaccional].
  * HistorialDAL.cs          : Registrar() e Historial filtrado ObtenerHistorial(desde, hasta, idUsuario, estado).

3. CONVENCIONES TÉCNICAS CRÍTICAS (NO ROMPER)
--------------------------------------------------------------------------------
1. COMPATIBILIDAD CON DISEÑADOR DE WINFORMS (.NET 8):
   - Cada Form y UserControl DEBE tener tres archivos correspondientes: *.cs, *.Designer.cs y *.resx.
   - En PausasActivasApp.csproj, cada formulario debe estar registrado con:
     <Compile Update="...cs"><SubType>Form o UserControl</SubType></Compile>
     <Compile Update="...Designer.cs"><DependentUpon>...cs</DependentUpon></Compile>
     <EmbeddedResource Update="...resx"><DependentUpon>...cs</DependentUpon></EmbeddedResource>
   - Si se omite el *.resx, el compilador lanzará NETSDK1004.

2. PREVENCIÓN DE BUCLES EN CIERRE DE SESIÓN:
   - Al cerrar sesión o cerrar una ventana contenedora, existe una bandera `_cerrando` booleana.
   - No invoques `this.Close()` dentro del evento `FormClosing` sin verificar `if (!_cerrando)` para evitar System.StackOverflowException.

3. ARCHIVO .EXE BLOQUEADO AL COMPILAR:
   - Si ejecutas la app y luego compilas con `dotnet build`, Windows bloqueará el binario (`MSB3026 / MSB3021`).
   - Siempre detén el proceso previo con: `Stop-Process -Name "PausasActivasApp" -Force -ErrorAction SilentlyContinue`.

4. EJECUCIÓN FUERA DEL SANDBOX:
   - Los comandos de build en entornos controlados requieren `BypassSandbox: true` para que el compilador de MSBuild pueda consultar el registro de Windows para el SDK de .NET 8.
